# FutureMate

Aplikasi CLI Python (PBO) yang menghubungkan belajar hari ini dengan target masa depan murid.

Jalankan (butuh Python 3.9+, tanpa library tambahan):

    cd futuremate
    python main.py

Tips demo: pilih menu 3 "Buat data demo", lalu masuk sebagai Murid dengan nama `Demo`.
Data jurusan di `data/jurusan.json` adalah data contoh, silakan ubah sesuai kebutuhan.
